# T-001 Plugin contracts

status: done
priority: P0
playbook: gtm-strategy
blockers: []

## Outcome

Create the plugin manifest, shared context, artifact contract, evidence policy, ticket schema, routing matrix, and scoring rules.

## Acceptance criteria

- The manifest validates with the official plugin validator.
- The JSON contract names the decision, tickets, artifacts, evidence, scores, and handoff.
- The evidence policy distinguishes facts, interpretations, hypotheses, and source errors.
- The invocation model is documented.
