# Customer success

Start from the customer's desired outcome and the evidence that shows progress.

## Steps

1. Define the customer outcome, stakeholders, timeline, current adoption, and success criteria.
2. Map milestones, risks, dependencies, enablement, and the next value event.
3. Separate measured progress from account assumptions and public signals.
4. Create a review cadence and escalation path for adoption or value gaps.
5. Identify an expansion hypothesis only after the core outcome is credible.

Use `../../references/evidence-policy.md`, `../../references/ticket-schema.md`, and `../../references/artifact-contract.md`.

## Completion

The plan has an agreed outcome, observable milestones, an owner, a review path, and a respectful expansion boundary.
