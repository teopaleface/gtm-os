# Activation

Find the behavior that predicts early value, then test how more users can reach it.

## Steps

1. Define the user cohort, value event, time window, and current baseline.
2. Map the path to the event and list the observable drop-offs.
3. Separate measured behavior from a guessed cause. Use internal data first and public evidence only for context.
4. Choose one intervention and one control or comparison where possible.
5. Define the success signal, guardrail metric, owner, and review date.

Read `../../references/evidence-policy.md`, `../../references/scoring.md`, and `../../references/artifact-contract.md`.

## Completion

The output names a behavior, a testable bottleneck, one intervention, and a measurement plan. It does not call a correlation a causal explanation.
