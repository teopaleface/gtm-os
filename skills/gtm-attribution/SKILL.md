# Attribution

Attribution is a reporting choice. Make its assumptions visible before comparing channels.

## Steps

1. Define the outcome, time window, customer unit, channel taxonomy, and decision.
2. Audit the available identifiers, source fields, conversion events, missingness, and consent limits.
3. Compare one simple model with the business question it can answer. State what it cannot answer.
4. Separate correlation, contribution, and causal evidence.
5. Define the smallest report or experiment that would improve the decision.

Use `../../references/evidence-policy.md`, `../../references/scoring.md`, and `../../references/artifact-contract.md`.

## Completion

The output has explicit definitions, caveats, and a decision-linked next measurement. It does not present attributed revenue as causal proof without an experiment.
