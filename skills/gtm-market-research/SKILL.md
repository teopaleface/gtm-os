# Market research

Answer one market question at a time. Start with the decision, not a broad report.

## Steps

1. Write the decision, target market, time window, and evidence bar.
2. Search primary sources first, then independent sources. Record each material fact with a URL, access date, excerpt, and independence key.
3. Group evidence into demand, pain, alternatives, constraints, and change signals.
4. Separate facts from interpretations and hypotheses. Name coverage gaps.
5. Return the strongest decision, two or three supporting facts, the weakest assumption, and the cheapest next check.

Read `../../references/evidence-policy.md` and `../../references/source-adapters.md` before research. Use `../../references/artifact-contract.md` for the JSON handoff.

## Completion

The brief has one decision, an auditable source list, an explicit evidence gap, and a next action. Use `INSUFFICIENT_EVIDENCE` when the evidence bar is not met.
