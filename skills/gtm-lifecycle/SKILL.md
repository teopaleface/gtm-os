# Lifecycle marketing

Use lifecycle messages to help a user take the next valuable action. Do not turn every inactivity signal into a campaign.

## Steps

1. Define the segment, lifecycle stage, value event, trigger, and desired action.
2. Check the evidence for the user's state and the consent or policy boundary for contact.
3. Draft the smallest helpful message with context, value, and a clear next step.
4. Set frequency, suppression, success, and guardrail rules.
5. Define a holdout or comparison and an owner for review.

Use `../../references/evidence-policy.md`, `../../references/scoring.md`, and `../../references/artifact-contract.md`.

## Completion

The message is useful for a defined state, has a measurement plan, and is ready for human approval before any send.
