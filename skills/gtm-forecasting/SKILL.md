# Forecasting

A forecast is a set of assumptions with a review date. It is not a promise.

## Steps

1. Define the outcome, period, unit, stage definitions, capacity, and decision.
2. Use observed pipeline, conversion, retention, seasonality, and capacity data where available.
3. Show low, base, and high cases with the arithmetic and the largest sensitivities.
4. Separate committed, likely, and exploratory work. State data freshness and missingness.
5. Define the review cadence and the signal that would change the forecast.

Read `../../references/evidence-policy.md`, `../../references/scoring.md`, and `../../references/artifact-contract.md`.

## Completion

Someone can reproduce the forecast, see its uncertainty, and know which new signal should update it.
