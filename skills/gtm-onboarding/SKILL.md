# Onboarding

Start from the user's first value, not from a tour of every feature.

## Steps

1. Define the target user, promise, first value event, time window, and prerequisites.
2. Map the user's current path, friction, unanswered questions, and handoffs.
3. Design the smallest sequence that reaches value. Assign a purpose to each step and message.
4. Add proof, recovery paths, instrumentation needs, and a human support option.
5. Define activation criteria and one experiment for the biggest drop-off.

Use `../../references/artifact-contract.md`, `../../references/scoring.md`, and `../../references/ticket-schema.md`.

## Completion

The path has a measurable first value event, clear user actions, recovery for common blockers, and an experimentable next step.
