# Outbound

Draft a reason to reach out, not a high-volume message blast. Relevance comes before copy.

## Steps

1. Define the ICP, buyer role, problem, trigger, offer, and disqualifier.
2. Identify the evidence needed to personalize safely. Use only public or user-provided information the user is allowed to use.
3. Draft a short message with the observed trigger, problem hypothesis, relevant value, and low-friction question.
4. Add a research checklist and a stop rule for weak fit or missing evidence.
5. Separate draft copy from send instructions. Ask for approval before any external send.

Read `../../references/evidence-policy.md`, `../../references/source-adapters.md`, and `../../references/artifact-contract.md`.

## Completion

The draft is specific, source-aware, respectful, and ready for human review. It does not claim intent from a weak signal.
