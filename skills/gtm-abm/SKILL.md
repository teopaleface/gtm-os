# Account-based marketing

Account selection is a research problem before it is a personalization problem.

## Steps

1. Define the ICP, account universe, value event, buying committee, and disqualifiers.
2. Rank accounts by fit, problem evidence, timing signal, access, and expected value.
3. Map known roles and public signals. Label the rest as unknown or hypothesis.
4. Draft one account hypothesis, relevant proof, and low-friction next step per priority account.
5. Add a human review gate before any outreach or CRM write.

Read `../../references/evidence-policy.md`, `../../references/source-adapters.md`, and `../../references/artifact-contract.md`.

## Completion

The list has a reasoned ranking, evidence-backed account hypotheses, and a safe handoff to a human owner.
