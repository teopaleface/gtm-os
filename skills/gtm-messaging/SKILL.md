# Messaging

Translate positioning into messages a buyer can recognize and a team can reuse.

## Steps

1. Start from one audience, one problem, and one desired change.
2. Collect the buyer's words from interviews, support, reviews, search, or supplied notes. Quote sparingly and cite the source.
3. Build a message map with headline, problem, value, how it works, proof, objection, and call to action.
4. Write variants for the buyer, user, champion, and approver when their concerns differ.
5. Flag claims that need proof and define one message test with a success signal.

Use `../../references/evidence-policy.md`, `../../references/artifact-contract.md`, and `../../references/scoring.md`.

## Completion

The message map has a clear audience, a specific problem, usable copy, cited proof, and one testable next action. Do not polish a message whose positioning is still undecided.
